Materi Komputasi Awan

Mengenal Teknologi Cloud Computing

Beranda Materi Komputasi Awan Portofolio Tugas

1. Pengertian Komputasi Awan

Komputasi awan (Cloud Computing) adalah teknologi yang memungkinkan pengguna mengakses sumber daya komputer, seperti penyimpanan, server, aplikasi, dan layanan melalui jaringan internet tanpa harus memiliki perangkat atau server sendiri.

2. Jenis Layanan Komputasi Awan

a. Software as a Service (SaaS)

SaaS merupakan layanan perangkat lunak yang dapat digunakan melalui internet tanpa perlu menginstal dan mengelola aplikasi secara langsung. Contoh: Google Drive, Gmail, dan Microsoft 365.

b. Platform as a Service (PaaS)

PaaS merupakan layanan yang menyediakan platform untuk mengembangkan, menjalankan, dan mengelola aplikasi tanpa harus mengatur infrastruktur server. Contoh: Google App Engine dan Heroku.

c. Infrastructure as a Service (IaaS)

IaaS merupakan layanan penyediaan infrastruktur komputer melalui internet, seperti server virtual, penyimpanan, dan jaringan. Contoh: Amazon Web Services (AWS) dan Microsoft Azure.

3. Manfaat Komputasi Awan

  • Menghemat biaya pembelian perangkat keras.
  • Data dapat diakses melalui internet.
  • Memudahkan penyimpanan dan berbagi data.
  • Dapat meningkatkan kapasitas sesuai kebutuhan.
  • Mendukung pekerjaan dari berbagai lokasi.

4. Risiko Komputasi Awan

  • Ketergantungan pada koneksi internet.
  • Risiko kebocoran atau pencurian data.
  • Gangguan layanan dari penyedia cloud.
  • Ketergantungan pada penyedia layanan.
